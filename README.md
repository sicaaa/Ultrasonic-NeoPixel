# ultrasonic x neopixel LED

The aim of this project is to change the color of the NeoPixel LED regarding to the Ultrasonic Sensor HC-SR04 measurements.


## Components

Ultrasonic Sensor HC-SR04: [(https://botland.de/ultraschall-abstandssensoren/1420-ultraschall-abstandssensor-hc-sr04-2-200cm-justpi-5903351241366.html)](https://www.roboter-bausatz.de/p/hc-sr04-ultraschallsensor)]([https://www.roboter-bausatz.de/p/hc-sr04-ultraschallsensor](https://botland.de/ultraschall-abstandssensoren/1420-ultraschall-abstandssensor-hc-sr04-2-200cm-justpi-5903351241366.html))

RGB LED: [[(https://botland.de)](https://botland.de/led-dioden/10617-neopixel-ws2812b-5mm-led-5st-adafrucht-1938-5904422301002.html)
